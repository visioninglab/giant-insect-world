# Giant Insect World

A touring exhibition website for Giant Insect World — an immersive, interactive experience celebrating the extraordinary world of insects.

## About

Giant Insect World is a large-scale touring exhibition that brings visitors face-to-face with the fascinating and often overlooked world of insects. The website supports the touring programme, providing information for venues, visitors, and partners.

## Developed by

[Visioning Lab](https://www.visioninglab.com) — research, design and technology studio based in Manchester.
